ML Virtual Portfolio

In this project I intend to simulate a paper-trading portfolio using my own knowledge in combination with the methods from my most recent read: López de Prado's Machine Learning for Asset Managers

The project will include a data pipeline, research elements and a web dashboard

The workflow will be as follows: Ingestion -> Cleaning -> Features -> Models -> Paper Trader -> FastAPI -> Dashboard

I intend to use free resources to build this project. It will be developed locally, while the live paper portfolio will run on a VPS, updating daily and rebalancing monthly

The dashboard will show the portfolio's performance against its benchmarks, its current allocation and the research results behind it

I will use a universe of ETFs due to data reliability and availability considerations
